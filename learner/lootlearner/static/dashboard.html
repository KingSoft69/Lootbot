    First time

    1. Start proxy, then Log in and follow the code in the console (microsoft.com/link).
    2. Join localhost in Minecraft. Give the bot its gear (elytra, rockets, food, pickaxe, totems) and stand it next to empty chests or barrels.
    3. Save kit, then Set home here.
    4. Disconnect (the bot only works while nobody controls it) and press Start looting on the Bot tab.

    Watch it in Minecraft

    Join to watch: joining localhost puts you inside the bot's view as a spectator, and it keeps looting. Join to control: joining takes over (for gear and kit).
