Join localhost in Minecraft as a spectator and see exactly what the bot sees, while it keeps working.
First time
  1. Start the proxy, then Log in and follow the code in the console.
  2. Join localhost in Minecraft. Give the bot its gear (elytra, rockets, food, pickaxe, totems) and stand it next to empty chests or barrels.
  3. Save kit, then Set home here.
  4. Disconnect from the proxy (the bot only works while nobody controls it) and press Start looting.
  5. To watch it work, put in your Minecraft name, press Join to watch and join localhost again.
